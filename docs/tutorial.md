Learn how to create a Sunday worship presentation from start to finish.

The tutorial builds a service with an invocation, three songs, and a Scripture reading. It demonstrates program management, the streaming/in-person preview toggle, separate title and lyric formatting, background pan/zoom/flip/opacity, keyboard navigation, the five image styles, full-size image viewing, Google image search, PowerPoint creation, and an actual upload followed by opening the Drive folder. It also shows the feedback link.

Recorded with v0.93.37 using fresh app and browser captures. The PIP toggle only shows or hides the presenter guide; text layout, size, position, and slide count remain unchanged.
