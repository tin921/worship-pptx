# 使用說明

1. 在左欄設定崇拜名稱及日期。
2. 選擇上方詩歌或經文分頁。所有歌詞在同一欄輸入：

   ```text
   [v1]
   今天聚集在主跟前
   同心獻上感恩頌讚

   [c]
   願我一生為祢而活
   讓祢的愛充滿我心
   ```

3. 在「演唱次序」輸入 `v1 c v1 c c`。大小寫均可，以空格或逗號分隔。
   不填次序時，依歌詞中的段落次序播放。未標記段落的詩歌須清空演唱次序。
4. 空行強制分頁；每頁最多三行。長句按目前字體的實際寬度自動換行。
   經文直接輸入，毋須段落標記。
5. 點擊背景中央「編輯背景」，選擇檔案、直接圖片網址、拖放或貼上圖片。
   在網址輸入欄按 Ctrl+V 會貼上網址；按「載入圖片」取得圖片。
   在其他位置按 Ctrl+V 或按貼上按鈕可讀取剪貼簿中的圖片、檔案或網址。
6. 選擇香港黑體或香港宋體。此選擇適用於整個崇拜，並隨紀錄儲存。
7. 點選右側縮圖檢查分頁，或按「預覽整個崇拜」。用左右鍵／空白鍵翻頁，Esc 關閉預覽。
8. 按「製作 PowerPoint」，選擇儲存位置。程式不會自動上載；如需要，可自行把檔案存入共享資料夾。

圖片支援 PNG、JPEG、BMP、GIF（第一幀）、TIFF（第一頁），最多 25 MB、4,000 萬像素。
圖片會置中裁切填滿 16:9，匯入後複製到本機圖片庫。網址必須直接傳回圖片，不是一般網頁。
不支援需要登入的網站或瀏覽器 cookie。取消背景對話框不會更換目前背景。

![背景圖片的四種輸入方式](background-input.png)

CCLI Song Number 是個別詩歌編號；教會 Licence Number 在「設定」只需填一次。
本程式不提供 SongSelect 搜尋、歌詞下載或 CCLI 使用回報。示例歌詞為原創內容。

## 儲存與備份

資料儲存在 `%LOCALAPPDATA%\WorshipPptx`：`services` 是 JSON 紀錄、`images` 是圖片、
`settings.json` 是教會設定。請備份整個資料夾。每次修改後約 0.65 秒自動儲存；Ctrl+S 立即儲存。
即使歌詞尚未完整或次序有錯，草稿仍會儲存；匯出時才要求修正。
移除或新增安裝程式不會刪除這個資料夾。解除安裝也保留崇拜紀錄。

新建崇拜會提供可修改的示例內容；按左側紀錄可重新開啟舊安排。
