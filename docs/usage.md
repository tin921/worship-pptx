# 使用說明

1. 在頂部分頁前方設定崇拜名稱及日期；名稱仍可直接編輯，兩個欄位與分頁垂直置中。新建崇拜預設為即將到來的星期日（當天為星期日則使用當天），日期欄保留月曆選擇。
2. 選擇上方詩歌或經文分頁，亦可拖放分頁更改整個崇拜的次序。空白欄位內會顯示提示，滑鼠停留可查看欄位名稱。所有歌詞在左欄底部同一欄輸入：

   ```text
   [v1]
   今天聚集在主跟前
   同心獻上感恩頌讚

   [c]
   願我一生為祢而活
   讓祢的愛充滿我心
   ```

3. 在歌詞欄正上方的「演唱次序」輸入 `v1 c v1 c c`。大小寫均可，以空格或逗號分隔。
   不填次序時，依歌詞中的段落次序播放。沒有 [v1]、[c] 等段落標記時，按經文／公告處理，忽略原有演唱次序，不加入歌名頁或 CCLI。
4. 有段落標記的詩歌以空行強制分頁；半幅文字每頁最多三行，全幅文字每頁最多八行。文字範圍由下方快速畫面及攝影機位置決定。長句按目前字體、粗體及字號的實際寬度自動換行，較大字號會減少每頁行數。
   每首詩歌先顯示歌名頁，列出版權、CCLI 詩歌編號及已填寫的教會授權編號，再依演唱次序顯示歌詞。其後各頁只顯示歌詞，不重複版權或 CCLI。歌名頁沿用同一背景；經文不另加歌名頁。
   無標記的經文直接輸入；按字體、字號及半幅／全畫面實際空間自動分頁，沒有固定三行／八行限制。保留空行、行首及行內空格；空行佔一行，不再強制換頁。Tab 鍵可插入縮排，預覽及 PowerPoint 每個 Tab 以四個空格顯示。
   公告用 `[1]`、`[2]` 等分項，每項固定一頁；標記本身不會出現在投影片。字號設定為最大值，長公告會自動縮小，直至整項放入指定的半幅／全畫面；短公告仍使用所選字號。每項獨立計算，主預覽下方顯示該項實際字號。公告內的空行、空格及 Tab 縮排會保留。請勿與詩歌段落標記混用。
5. 點擊背景中央「編輯背景」，瀏覽內置素材，或選擇檔案、直接圖片網址、拖放或貼上圖片。
   圖庫可按核心／延伸主題、日光／夜色及攝影／插畫／抽象篩選。選中後按「套用背景」。
   開啟「編輯背景」時，會在本機分析目前歌名及歌詞，填入「主題＋三個視覺詞」，例如「屈膝禱告、屈膝剪影、雙手合十、柔和晨光」。關鍵字跟隨歌詞使用繁體中文、簡體中文或英文；未填歌詞則參考歌名。可自行修改，或按「重新配對」再次分析。分析期間顯示「正在擷取主題及關鍵字」及進度；載入本機模型時顯示不定進度，之後的百分比代表已完成分析步驟，並非剩餘時間。
   右方「Google 圖片搜尋」連結會跟隨關鍵字更新，點擊才開啟預設瀏覽器。以 OR 連接主題及各個關鍵詞組，例如 `(「屈膝禱告」 OR 「屈膝剪影」 OR 「雙手合十」 OR 「柔和晨光」) 背景`，並篩選橫向及大於 2MP 的圖片。輸入時用頓號、逗號、分號或 OR 分開詞組；英文詞組內的空格會保留。Google 沒有精確的 720p 最低尺寸選項；2MP 高於 720p 的像素總量，但實際長寬仍要以圖片為準。歌詞不會傳送給 Google。
   所有背景均使用靜態圖片，沒有動畫設定。
   在網址輸入欄按 Ctrl+V（Mac：⌘V） 會貼上網址；按旁邊的「載入」取得圖片。
   在其他位置按 Ctrl+V（Mac：⌘V） 或按貼上按鈕可讀取剪貼簿中的圖片、檔案或網址。
6. 背景縮圖在左，右方「文字格式」設定本分頁的字體、字號（18–72 pt）、粗體、靠左／置中／靠右、靠上／垂直置中／靠下圖示。色彩按鈕開啟 8×8（64 色）色塊格，毋須捲動；滑鼠停留可查看色名。各個詩歌／經文分頁的格式獨立儲存，切換分頁會顯示各自設定。舊崇拜會保留原有文字格式，再轉為分頁設定。
   字體清單中的名稱以該字體顯示。隨附八款可嵌入 PowerPoint 的字體：香港黑體、香港宋體、霞鶩文楷、粉圓、朱雀仿宋（古典印刷）、霞鶩漫黑（漫畫手寫）、馬善政毛筆（簡體）及站酷快樂（簡體、童趣）。粉圓以繁體字為主；馬善政及站酷快樂缺少不少繁體字，宜用於簡體內容。朱雀仿宋及霞鶩漫黑涵蓋常用繁簡字；完整繁簡文字可選香港黑體／宋體。亦可選用已安裝的常用 Windows／Mac 中文字體，播放電腦需要同樣字體。重複外觀的 Microsoft JhengHei UI、Microsoft YaHei UI 及 NSimSun 不再列出；舊紀錄會對應至 Microsoft JhengHei、Microsoft YaHei 及 SimSun。粗體使用該字體的可用粗體或合成粗體效果。
   歌名頁與歌詞有獨立的字號及「自動」設定。先選歌名頁縮圖，再調整字號；選歌詞縮圖時則調整所有歌詞。右上方會顯示「歌名字號」或「歌詞字號」。自動歌名字號按歌名及版權資料調整，不受最長歌詞段落影響；自動歌詞字號仍以最長段落統一計算。文字後方沒有灰色遮罩。歌名頁的版權及 CCLI 字號為主要文字的 60%；較長資料會換行，必要時按比例縮小歌名頁文字。
   「畫面預覽」下方的「畫面設定」按鈕可展開／收起畫中畫控制，預設收起。展開後左側有六個快速畫面：左上、右上、左下、右下畫中畫，以及全畫面投影片、全畫面攝影機。四角預設寬、高各 40%，離邊緣 2%；預設為右下。白色邊框及四角方形控制點一直顯示；可直接拖動畫中畫移位，拉動邊框或四角縮放，邊緣中間不顯示方形控制點。右側位置 X/Y 和大小 X/Y 均為完整畫面的百分比，位置由左上角起計；可直接輸入，或在欄位聚焦後以滑鼠滾輪每格調整 1%。畫中畫大小最少 10%，移動及縮放會限制在畫面內。
   下方「背景」及「畫中畫」可互換投影片和攝影機來源。攝影機畫中畫的中心位於上半部時，文字改放下半部；中心在下半部時，文字改放上半部。投影片本身位於畫中畫時，文字使用整個畫中畫；全畫面亦使用完整文字區。靠上／中／下圖示是在這個文字區內對齊。版面設定按分頁儲存，整個崇拜預覽亦使用同一版面。
   攝影機目前是人物示意，並非即時攝影機訊號。有 `[v1]`、`[c]` 等詩歌段落標記時，顯示戴十字架項鏈、彈結他的領唱；沒有詩歌段落標記的宣召、讀經及公告（包括 `[1]`、`[2]` 分項），顯示同一人物、同一服裝在透明講台前讀聖經。演唱次序留空的詩歌仍按原有段落次序演唱，保留領唱示意。主預覽及整個崇拜預覽使用相同判斷。匯出的 PowerPoint 保留完整投影片背景及相應上半部／下半部／全幅文字，不加入攝影機示意、控制框或將投影片縮成畫中畫。
7. 點選右側縮圖，再用上／下方向鍵選擇投影片，主預覽會即時更新。拖動兩條欄間分隔線可調整欄位、主預覽及縮圖欄的寬度。按「預覽整個崇拜」後，用左右鍵／空白鍵翻頁，Esc 關閉預覽。
8. 按「製作 PowerPoint」，選擇儲存位置。程式不會自動上載；如需要，可自行把檔案存入共享資料夾。

圖片支援 PNG、JPEG、WebP、BMP、GIF（第一幀），最多 25 MB、4,000 萬像素。
圖片會置中裁切填滿 16:9，匯入後複製到本機圖片庫。網址必須直接傳回圖片，不是一般網頁。
不支援需要登入的網站或瀏覽器 cookie。取消背景對話框不會更換目前背景。

## 儲存與備份

Windows 資料儲存在 `%LOCALAPPDATA%\WorshipPptx`，Mac 在 `~/Library/Application Support/WorshipPptx`：`services` 是 JSON 紀錄、`images` 是圖片、
`settings.json` 是教會設定。請備份整個資料夾。每次修改後約 0.65 秒自動儲存；Ctrl+S（Mac：⌘S）立即儲存。
即使歌詞尚未完整或次序有錯，草稿仍會儲存；匯出時才要求修正。
移除或新增安裝程式不會刪除這個資料夾。解除安裝也保留崇拜紀錄。

新建崇拜會提供可修改的示例內容；按左側紀錄可重新開啟舊安排。左側按崇拜日期由新至舊排列，過去日期的標題顯示灰色。修改崇拜名稱、日期或分頁名稱，左側會即時更新；新增、移除或重新排列分頁，清單亦會同步。
