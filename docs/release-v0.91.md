# Worship PPTX 0.91

The current worship slide editor shown in the README, with a redesigned interface and a built-in background library.

- Reorderable song, Scripture and announcement tabs with automatic saving and service history.
- Automatic lyric pagination, verse/chorus repeats, and one-slide announcements that fit their text.
- Per-tab fonts, colors, bold and alignment, with editable PowerPoint export and embedded Chinese fonts.
- 270 static 720p backgrounds, local AI theme matching, and image import from files, URLs, drag-and-drop or the clipboard.
- Adjustable picture-in-picture preview guides, six layout presets, and collapsible layout settings. Camera graphics are preview guides and are not included in PowerPoint exports.

## Downloads

- **WorshipPptx-0.91.0-Setup.msi** — Windows installer.
- **WorshipPptx-0.91.0-Portable.zip** — extract the entire folder and run `WorshipPptx.exe`.
- **SHA256SUMS.txt** — SHA-256 checksums for both downloads.

For Windows 10 22H2 or Windows 11, x64. The runtime, fonts, background library and local matching model are included; no separate .NET installation or API key is needed. Builds are unsigned.
