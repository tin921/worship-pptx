# Native capture procedure

Launch the current 0.93.37 Windows build using the isolated profile in `profile-path.txt`. Keep temporary files on E:.

1. Select 同心頌讚 and open its background picker. Click its actual Google image link, then capture the browser results before and after scrolling.
2. Return to the picker. Double-click a result to open its full image, capture it, and double-click again to verify closing. Cancel the picker to retain the demonstration background.
3. Click Create, capture the native save dialog, save a demonstration PowerPoint inside `output/`, and capture the success status.
4. Upload the demonstration deck through the native app. After success, click its actual folder link, verify the uploaded filename in Drive, and capture the folder and filename bounds.
5. Click the feedback icon and capture the actual Google document without editing it.

Use the computer-use skill's Sky API with fresh observations and one action followed by refresh. Save screen pixels only as production assets. Browser authentication and permissions are unchanged. `native/verification.json` records the completed native interaction checks. No credentials or upload key are stored here.
