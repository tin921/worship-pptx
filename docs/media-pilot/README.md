# Worship background pilot

Open `index.html` in Edge or Chrome. Everything runs locally, without a web server or account. The gallery compares four versions for each of five songs and can overlay original sample Chinese text in the upper half. The guide and sample text are never baked into the assets.

Also available: [six generic mood backgrounds](generic/index.html), each with daylight and night versions of a still image and a five-second loop — soft snow, gentle rain, golden lights, paper flight, petals and flowing ribbons. The new daylight assets are 720p with dark sample lyrics. These can be chosen by mood without matching a particular song.

These are five familiar song references chosen for a varied pilot, **not a verified current top-five chart**. Public sources did not establish a comparable current ranking across Chinese churches. The same title can refer to different songs: the fourth reference here is the River of Life song, not the SEMM song in the earlier research table. All theme-to-scene choices in this pilot were reviewed as design interpretations; they are not claimed to be fresh embedding-model output.

Each song folder contains:

- `graphic.png`: original code-native graphic, 1920 × 1080.
- `graphic-loop.mp4`: matching five-second graphic animation, 1920 × 1080, 30 fps.
- `photo.png`: original AI-generated photorealistic still, preserved at its generated dimensions.
- `photo-loop.mp4`: five-second animated still, with very small periodic camera drift, 1920 × 1080, 30 fps.

The photo loops **do not contain generated natural movement** of water, plants, clouds or the eagle. A connected image-to-video service is needed for that next stage. Runway was found as an available option but was not connected or used. Future video prompts are included in `prompts.json`; no footage from the referenced songs was used.

The five photos were made with the built-in image-generation tool. Full prompts are in `prompts.json`. The graphics and both kinds of loop are generated by `../../experiments/media-pilot/render.cjs`. Motion is exactly periodic at five seconds. There are 150 frames per MP4; the duplicated endpoint is deliberately omitted to avoid a pause. Encoding uses H.264, yuv420p and no audio. `validation.json` records asset hashes, dimensions, full frame decoding and measured seam differences; `render-validation.json` proves source-frame equality at t=0 and t=5. `gallery-validation.json` records browser playback and controls checks. No app screenshots were taken.

## Using the files

PNG images can be used as slide backgrounds. Insert MP4 files as video objects behind the lyric text, set them to start automatically and loop until stopped. Microsoft recommends [H.264 MP4 for PowerPoint](https://support.microsoft.com/en-us/powerpoint/video-and-audio-file-formats-supported-in-powerpoint); see also [video playback options](https://support.microsoft.com/office/set-the-play-options-for-a-video-in-your-presentation-f0d5b3f1-37ba-4a0d-9d94-f8e33cef29bf). A source loop does not guarantee uninterrupted playback across slide changes. PowerPoint is not installed on this computer, so its playback and loop gap have not been tested. The app's image input/export has not been extended to video in this pilot.

All frames leave the upper half visually quiet for lyrics. These five song-inspired sets are intentionally dark enough for white text; the separate generic daylight collection uses dark text on light backgrounds. No lyrics, music, publisher logos or existing cover/MV art are included. Song titles identify the inspiration, not publisher endorsement.

## Extending to 60–80 themes

Keep assets theme-based, with separate song-to-theme mappings. Reuse a suitable scene for multiple songs. Store the theme ID, style, palette, quiet text region, motion type and provenance alongside each asset. Begin with 60 core scenes, keep the 20 rare motifs available when lyrics call for them, and approve one still per visual direction before producing more variations or paid natural-motion videos. Five seconds is the pilot target; 10–15 seconds may feel less repetitive for flowing water and clouds.

No application code, installer, release or remote repository was changed by this pilot.
