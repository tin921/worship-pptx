# Worship PPTX v0.93.38

Adds 16 Chinese fonts, bringing the bundled selection to 24. The new choices
include brush calligraphy, historical print, handwriting, rounded lettering,
playful display faces and pixel lettering. Fonts load directly from the app;
no system installation is needed.

The picker labels known limitations in character or punctuation coverage.
All new fonts support editable PowerPoint embedding. The original font files,
licences, pinned sources, preparation scripts and coverage fixtures are included
in the repository. The two fonts supplied in CFF format are converted to static
TrueType for PowerPoint compatibility.

Windows x64 installer and portable packages include the fonts, background
library, offline matching model and required runtime dependencies. User service
history and upload credentials are excluded.

Validation: 162 checks passed, including all 24 font faces, Windows font
embedding, PowerPoint exports and layout behavior. Package validation compares
every MSI and ZIP payload file against the release build. The installer is
extracted for verification; no native MSI installation is performed.
